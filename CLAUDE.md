# Инструкции для Claude

- Все отчёты и итоговые сообщения (финальные отчёты по задачам, сводки результатов) — писать на русском языке.
- Каждый отчёт отдавать в виде, пригодном для копирования, **не дожидаясь отдельной просьбы**: сохранить его файлом в `docs/`, отправить этот файл пользователю и продублировать текст целиком в ответе одним блоком кода. Отчёт, существующий только в переписке, считается невыданным.
