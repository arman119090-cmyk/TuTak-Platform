# Инструкции для Claude

- Все отчёты и итоговые сообщения (финальные отчёты по задачам, сводки результатов) — писать на русском языке.
- Каждый отчёт отдавать в виде, пригодном для копирования, **не дожидаясь отдельной просьбы**: сохранить его файлом в `docs/` и отправить этот файл пользователю. Отчёт, существующий только в переписке, считается невыданным.
- **Текст отчёта в ответе не дублировать.** Файл уже пригоден для копирования и передачи дальше; повтор того же текста в переписке — лишний. В ответе достаточно нескольких строк: главный вывод и что требуется от читателя.
