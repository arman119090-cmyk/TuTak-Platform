# TuTak — посмотреть приложение на телефоне

Пять шагов. Ничего устанавливать, кроме Node.js и Expo Go, не нужно.

## 1. Установите на телефон Expo Go

Android — [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent).
iPhone — App Store.

## 2. Скачайте репозиторий

На странице проекта на GitHub: зелёная кнопка **Code** → **Download ZIP**.
Распакуйте.

## 3. Откройте папку `demo`

Именно `demo`, а не корень репозитория. В VS Code: **File → Open Folder** →
выбрать `demo`.

## 4. Выполните две команды

Терминал в VS Code: **Terminal → New Terminal**. Затем:

```
npm install
npx expo start
```

Первая идёт две-три минуты и нужна один раз. Вторая запускает и показывает
QR-код прямо в терминале.

## 5. Отсканируйте QR-код

Android — камерой внутри Expo Go. iPhone — обычной камерой, появится
предложение открыть.

Телефон и компьютер должны быть в одной сети Wi-Fi.

---

## Как войти в приложение

На первом экране нажмите **«Войти в демо»**. Ни регистрации, ни пароля.

Хотите пройти регистрацию целиком — можно: любые имя, номер и пароль от
восьми символов подойдут, код подтверждения тоже любой. Проверять их нечему,
сервера нет.

## Что можно посмотреть

Все экраны приложения: главный, кошелёк с бонусами и историей, QR-код для
оплаты, сканер, зарядные станции с идущей сессией, приглашения друзей,
уведомления, профиль и настройки.

Данные вымышленные, но живые. Оплата по QR и остановка зарядки меняют баланс.
Прочитанное уведомление становится прочитанным. Всё держится в памяти
телефона и сбрасывается при перезапуске.

На экране сканера есть кнопка **«Сымитировать сканирование»** — она есть
только здесь. В настоящем приложении код показывает продавец, а в демо
показать его некому.

## Если что-то пошло не так

| Что видно | Что делать |
| --- | --- |
| Белый экран или «Something went wrong» в Expo Go | Остановить (Ctrl+C) и запустить `npx expo start -c` |
| QR-код не открывается, телефон «не видит» компьютер | Одна сеть Wi-Fi. Если сеть гостевая или офисная — `npx expo start --tunnel` |
| `npx: command not found` | Установить Node.js 20 или новее с nodejs.org |
| Чёрный экран в разделе сканера | Expo Go просит доступ к камере — разрешить. Или пользоваться кнопкой «Сымитировать сканирование» |

## Чем это отличается от настоящего TuTak

Это **не отдельный макет**. Экраны, навигация, состояние, разбор ответов —
тот же код, что в рабочем приложении. Подменён только источник данных.

Настоящий TuTak со всей серверной частью — база, платежи, зарядки, панели
администратора и партнёра — никуда не делся и лежит в том же репозитории.
Как его запустить, написано в [`README.md`](README.md) и
[`docs/TESTING_RU.md`](docs/TESTING_RU.md).

Демо не умеет и никогда не будет уметь: настоящие деньги, настоящие SMS,
настоящую регистрацию, push-уведомления. Приём любого пароля здесь безопасен
ровно потому, что эта версия физически отделена от рабочей — см.
`apps/mobile/src/data/api/mockGate.ts`.
