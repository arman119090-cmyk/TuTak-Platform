# Hoviki Mebel — демонстрационный интернет-магазин мебели

Рабочий магазин мебели и дверей: каталог на 280+ товаров, корзина с серверным
расчётом, оформление заказа в 7 шагов, личный кабинет, админ-панель,
конфигуратор дверей, калькулятор кухни и три языка интерфейса (հայերեն,
русский, English).

Это демонстрация: заказы никуда не уезжают, оплата имитируется, товары и
юридические тексты вымышлены. Всё остальное — настоящее: PostgreSQL, миграции,
серверная авторизация, серверный расчёт цены заказа.

---

## Быстрый старт

Нужны Node.js 20+ и PostgreSQL. База поднимается одной командой через Docker:

```bash
cd apps/shop
docker compose up -d      # PostgreSQL на localhost:5432
npm install
npm run setup             # .env + миграции + демо-данные
npm run dev               # http://localhost:3100
```

`npm run setup` создаёт `.env` из `.env.example`, применяет миграции и
наполняет базу. Если PostgreSQL уже есть — пропустите `docker compose up`,
укажите свой `DATABASE_URL` в `.env` и запустите `npm run setup`.

Полностью в контейнерах (магазин + база):

```bash
SEED_ON_START=1 docker compose --profile app up --build
```

| Код | Что делает |
| --- | --- |
| `WELCOME10` | −10% от 100 000 ֏, максимум 120 000 ֏ |
| `SOFA50` | −50 000 ֏ при заказе от 300 000 ֏ |

| `DEMO25` | −25% и бесплатная доставка |

## Сценарий демонстрации

1. Главная → **Диваны** → фильтр «Только в наличии» → карточка товара.
2. Выбрать цвет и материал (цена пересчитывается) → **В избранное** →
   **Сравнить** → **В корзину**.
3. Корзина → промокод `DEMO25` → **Оформить заказ**.
4. Checkout: контакты → адрес → доставка → услуги → оплата
   (есть кнопка «Смоделировать отказ банка») → проверка → подтверждение.
5. `/admin` под администратором → заказ виден в списке → сменить статус →
   изменение сразу видно покупателю в «Мои заказы».
6. **Кухни** → «Рассчитать кухню»: оценка считается на лету, заявка попадает в
   `/admin/requests`.
7. **Двери** → карточка двери → конфигуратор (размер, покрытие, коробка,
   наличники, ручка, замок, установка) → цена пересчитывается → в корзину.

### Изображения

Фотографий нет и внешних источников нет: каждая карточка получает 4
детерминированно сгенерированных SVG-изображения (студийный кадр, ракурс,
деталь, интерьерная сцена) в цвете самого товара. Генератор —
`src/lib/media/artwork.ts`, раздача — `/media/art/[slug]`. Поэтому демо не
зависит от чужих CDN и не тянет за собой бинарные файлы в git.

## Команды

```bash
npm run dev            # дев-сервер, порт 3100
npm run build          # production-сборка
npm run start          # запуск собранного приложения
npm run setup          # .env + миграции + seed
npm run seed           # только пересоздать демо-данные
npm run prisma:migrate # prisma migrate deploy
npm run test           # unit-тесты (Vitest)
npm run test:e2e       # E2E-тесты (Playwright)
npm run typecheck      # tsc --noEmit
npm run lint           # ESLint
npm run verify         # typecheck + unit-тесты + build
```

E2E поднимает собственный сервер (или переиспользует запущенный на 3100) и
повышает для него лимит попыток входа `AUTH_RATE_LIMIT_MAX` — прогон логинится
десятки раз с одного адреса, и production-лимит (10 за 5 минут) справедливо
начал бы его отклонять. В обычном запуске переменную задавать не нужно.

## Белый лейбл

Название, монограмма логотипа, телефоны, почта, мессенджеры, адрес, домен и
валюта вынесены в `src/config/brand.ts` и переменные окружения
(`NEXT_PUBLIC_BRAND_*`). Чтобы сменить бренд, код трогать не нужно — достаточно
`.env`:

```bash
NEXT_PUBLIC_BRAND_NAME="Hoviki Mebel"
NEXT_PUBLIC_BRAND_NAME_HY="Հովիկի Մեբել"
NEXT_PUBLIC_BRAND_NAME_RU="Ховики Мебель"
NEXT_PUBLIC_BRAND_NAME_EN="Hoviki Mebel"
NEXT_PUBLIC_BRAND_MONOGRAM="H"
NEXT_PUBLIC_BRAND_PHONE="091200009"
NEXT_PUBLIC_BRAND_PHONE_SECONDARY="095200003"
```

Название магазина — такая же переводимая строка, как и всё остальное: в
армянской версии сайта в шапке, подвале, `<title>`, Open Graph и JSON-LD стоит
`Հովիկի Մեբել`, в русской — `Ховики Мебель`, в английской — `Hoviki Mebel`.
Если название везде должно быть одним латинским словом, оставьте
`NEXT_PUBLIC_BRAND_NAME_HY/RU/EN` пустыми — тогда во всех языках подставится
`NEXT_PUBLIC_BRAND_NAME`. Написания на других языках попадают в JSON-LD как
`alternateName`, чтобы поиск связывал их с одной организацией.

Телефон можно писать как угодно — `091200009`, `+37491200009` или
`+374 91 200009`: приложение само приведёт его к виду `+374 91 200009` для
показа и к `tel:`-ссылке для звонка. Второй номер необязателен: если оставить
`NEXT_PUBLIC_BRAND_PHONE_SECONDARY` пустым, везде останется один.

Ничего технического бренд не содержит: cookie, ключи localStorage и имена
контейнеров называются `shop_*` / `furniture-shop-*`, поэтому переименование
магазина не ломает корзины и сессии.

Палитра и типографика — токены в `@theme` в `src/app/globals.css`.

## Деплой

`Dockerfile` собирает production-образ; миграции применяются при старте
контейнера, seed — только если задать `SEED_ON_START=1`.

Для Railway / Render / Fly: подключите PostgreSQL и задайте переменные
`DATABASE_URL`, `AUTH_SECRET`, `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_DEMO_MODE`.
Vercel тоже подходит (Next.js), базу в этом случае берут у внешнего провайдера.

`npm run setup` сам генерирует уникальный `AUTH_SECRET` при первом запуске.
Если вы создаёте `.env` вручную — сгенерируйте секрет сами:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

В production приложение откажется подписывать сессии значением-заглушкой из
`.env.example` — это намеренная защита, а не ошибка конфигурации.

## Что является mock

- **Оплата.** Реальной банковской интеграции нет. Карточная оплата помечается
  успешной или отклонённой по выбору в интерфейсе.
- **SMS/OTP.** Код всегда `111111`, провайдер не подключён.
- **E-mail.** Письма не отправляются (в success-странице текст «мы отправили
  подтверждение» — демонстрационный).
- **Расчёт кухни.** Оценка по прайсу за погонный метр, а не результат замера.
- **Доставка.** Тариф по регионам фиксированный, без расчёта по адресу.
- **Тексты оферты, политики и гарантии** — демонстрационные, не юридические.

Подробный разбор того, что нужно заменить для настоящего запуска, — в
[`docs/2026-09-21-furniture-demo-shop.md`](../../docs/2026-09-21-furniture-demo-shop.md).
