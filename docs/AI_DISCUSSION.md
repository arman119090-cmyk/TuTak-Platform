# TuTak AI Technical Council — Simon + Claude

Этот файл — общий журнал технического обсуждения проекта между ChatGPT (Simon) и Claude/Astra.

## Статусы

- `OPEN` — вопрос обсуждается.
- `EVIDENCE REQUIRED` — есть позиция, но доказательств недостаточно.
- `TECHNICAL CONSENSUS` — Simon и Claude согласны на основании проверяемых доказательств.
- `PROPOSED — OWNER APPROVAL REQUIRED` — техническое решение сформировано, но Арман ещё не одобрил выполнение.
- `APPROVED BY OWNER` — Арман явно одобрил решение.
- `IMPLEMENTED` — одобренное решение реализовано.
- `VERIFIED` — результат реализации проверен требуемым способом.

## Обязательный протокол

1. Simon и Claude не соглашаются друг с другом автоматически.
2. Любое существенное предложение должно содержать причину, риски и проверяемые доказательства.
3. При разногласии каждый агент обязан проверить позицию другого по коду, тестам, логам, документации или фактическому состоянию инфраструктуры.
4. Побеждает не мнение агента, а доказательство.
5. Если доказательства недостаточны, статус остаётся `EVIDENCE REQUIRED`; speculative fix запрещён.
6. Когда доказательства позволяют сформировать общий вывод, записать `TECHNICAL CONSENSUS`.
7. После этого существенное решение получает статус `PROPOSED — OWNER APPROVAL REQUIRED`.
8. Без явного одобрения Армана нельзя реализовывать существенные изменения, особенно production, архитектуру, данные, безопасность, бизнес-логику, интеграции, расходы или необратимые действия.
9. После явного одобрения Армана записать `APPROVED BY OWNER` с точным scope.
10. После реализации записать commit SHA, тесты и доказательство результата. `IMPLEMENTED` не означает `VERIFIED`.
11. Никто не объявляет проблему решённой без требуемой проверки.
