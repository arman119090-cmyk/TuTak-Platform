# Current AI Task

Этот файл предназначен для текущей задачи, которую пользователь передаёт Claude/Astra/ChatGPT.

## Как использовать

1. Перед началом прочитать `docs/AI_SHARED_CONTEXT.md`.
2. Прочитать этот файл полностью.
3. Прочитать все дополнительные документы, на которые здесь есть ссылки.
4. Не выходить за scope задачи.
5. Не делать destructive production changes без явного разрешения пользователя.
6. После завершения обновить `docs/AI_HANDOFF.md`.

## Текущая задача

На момент создания структуры активная задача здесь не зафиксирована намеренно.

Перед следующей работой агент должен получить от пользователя конкретную задачу и записать/обновить её в этом файле либо работать по краткой инструкции пользователя, если она однозначна.

## Формат рекомендуемой постановки задачи

- Цель
- Репозиторий/ветка
- Обязательные документы для чтения
- Что уже доказано
- Что нельзя повторять
- Scope
- Пошаговый план
- Success criteria
- Tests/builds
- Запрещённые изменения
- Формат итогового отчёта
