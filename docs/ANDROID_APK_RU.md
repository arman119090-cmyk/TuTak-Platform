# APK для Android — сборка и установка на Pixel

Как получить установочный файл приложения и поставить его на телефон.
Всё делается с телефона, компьютер не нужен.

---

## Сначала — какая сборка вам нужна

Их две, и разница принципиальная.

| | **preview** | **development** |
|---|---|---|
| Работает сам по себе | **да** | нет |
| Нужен компьютер рядом | нет | **да**, с запущенным Metro |
| Для чего | показать продукт, дать инвестору | ежедневная разработка |

**Берите `preview`.** «Development build» — это сборка, которая при каждом
запуске подключается к серверу разработки на компьютере в той же сети. У вас
компьютера нет, значит такое приложение просто не откроется дальше заставки.

Я оставил и профиль `development` — он понадобится вашему разработчику. Но
телефон, который вы дадите в руки другому человеку, должен быть с `preview`.

---

## Что нужно один раз

**1. Аккаунт Expo** — бесплатный, expo.dev, регистрация через GitHub.

**2. Токен доступа.** На expo.dev: **Account settings → Access tokens →
Create token**. Скопируйте — он показывается один раз.

**3. Положить токен в GitHub.** Откройте репозиторий → **Settings** →
**Secrets and variables** → **Actions** → **New repository secret**:

- Name: `EXPO_TOKEN`
- Secret: вставьте токен

**4. Адрес API.** Приложение должно куда-то обращаться. Если вы подняли демо
по `docs/INVESTOR_DEMO_RU.md` — это адрес сервиса `tutak-api` с `/v1` на
конце, например `https://tutak-api-a1b2.onrender.com/v1`.

> **Без работающего API приложение установится и откроется, но войти будет
> некуда.** Сначала демо, потом APK.

---

## Собрать APK

1. Репозиторий на GitHub → вкладка **Actions**
2. Слева **Build Android APK**
3. **Run workflow**
4. Заполните:
   - **api_base_url** — адрес из пункта 4 выше, обязательно с `/v1`
   - **profile** — `preview`
5. **Run workflow**

Сборка идёт **15–25 минут**. Первая дольше — Expo создаёт ключ подписи.

Если что-то заполнено неверно, задача упадёт **в первые секунды** с понятным
сообщением, а не через двадцать минут. Это сделано специально.

## Забрать и установить на Pixel

Когда задача позеленеет:

1. На Pixel откройте **expo.dev** → ваш аккаунт → проект **tutak** → **Builds**
2. Верхняя сборка — там **QR-код** и кнопка **Download**
3. Нажмите **Download** (или наведите камеру Pixel на QR)
4. Скачается файл `.apk` — откройте его из уведомления о загрузке
5. Android скажет: **«Установка из неизвестных источников запрещена»** —
   это нормально для приложения не из Play. Нажмите **Настройки** →
   разрешите установку для браузера/Файлов → вернитесь назад
6. **Установить** → **Открыть**

При первом запуске приложение попросит доступ к **камере** — он нужен для
сканирования QR-кодов оплаты. Микрофон приложение не запрашивает.

## Если что-то пошло не так

| Что видите | Почему | Что делать |
|---|---|---|
| Задача падает сразу, «EXPO_TOKEN is not set» | Секрет не добавлен | Пункт 3 выше |
| Падает сразу, «does not end in /v1» | Забыли `/v1` в адресе | Перезапустить с правильным адресом |
| Падает сразу, «points at the phone itself» | Вписали `localhost` | Нужен адрес сервера, а не телефона |
| APK ставится, но войти нельзя | API недоступен | Откройте `адрес-api/health` в браузере — если не отвечает, сервис спит или не поднят |
| «Приложение не установлено» | Уже стоит версия с другой подписью | Удалите старую и поставьте заново |
| Открывается и сразу закрывается | Обычно несовпадение версии | Пришлите мне снимок экрана сборки на expo.dev |

## Обновить приложение

Изменился код или адрес API — просто запустите задачу ещё раз и поставьте
новый APK поверх старого. Удалять предыдущий не нужно, пока подпись та же.

---

## Чего в этой сборке нет

- **Push-уведомления на Android не будут приходить.** Для них нужны
  учётные данные Firebase (FCM), а их пока нет. Приложение спросит разрешение
  и получит его — но сообщения не придут. На демонстрации это не видно.
- **Настоящих платежей нет.** Эквайер в демо — песочница. Ни одна карта не
  списывается.
