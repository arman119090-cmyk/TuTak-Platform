# Проверка Android-сборки на телефоне

Дата: 19.09.2026. Сборка: GitHub → Actions → «Build Android APK» →
run #58 (из `main` `369eda1`, профиль `production-apk`, API
`https://tutak-api-production.up.railway.app/v1`) → Releases → скачать
APK. Нужны **два телефона: Samsung и Xiaomi**. На каждом — все шаги.

Перед началом: старую версию TuTak удалить. Установить APK.

| # | Шаг | Что должно быть | Если нет — записать |
|---|---|---|---|
| 1 | Открыть приложение, нажать «Регистрация», ввести номер | Поле принимает ввод, клавиатура не закрывается сама | модель, что произошло |
| 2 | Получить SMS-код, ввести | Код принят, переход дальше | пришёл ли SMS, за сколько секунд |
| 3 | Придумать пароль, ввести имя | Оба поля принимают ввод; переход между полями работает; клавиатура не «прыгает» | **это старый дефект: если фокус слетает или второе поле не берётся — стоп, видео** |
| 4 | Выйти из аккаунта (Настройки → Выйти) | Экран входа | — |
| 5 | Войти по паролю: номер + пароль (два поля) | Второе поле получает фокус, ввод идёт, вход успешен | **главная проверка фокуса**: снять видео 10 секунд |
| 6 | Главный экран → найти партнёра / отсканировать QR ветки | Камера открывается, QR читается, партнёр найден | — |
| 7 | Сделать покупку: ввести сумму, показать код кассиру, кассир подтверждает в Partner-панели | Покупка становится «Подтверждена», появился кешбэк | сумма, размер кешбэка |
| 8 | История | Покупка в списке с верной суммой | — |
| 9 | Закрыть приложение полностью, открыть снова | Остались в аккаунте, данные на месте | — |
| 10 | Свернуть приложение на 20 минут, вернуться | Работает без повторного входа (или просит войти — тоже нормально, записать) | — |

Прислать: модель и версия Android каждого телефона; видео шагов 3 и 5;
скриншот шага 7; список пунктов «если нет».

Результат считается **ANDROID DEVICE VERIFIED**, если все 10 шагов прошли
на обоих телефонах. Иначе — **ANDROID BLOCKED: <номер шага и что случилось>**.
