## Перед стартом (для сбора данных по бывшему дефекту клавиатуры)

1. Записать: модель, версия Android, версия One UI / MIUI (HyperOS),
   **какая клавиатура стоит по умолчанию** (Samsung Keyboard / Gboard /
   SwiftKey / другая) и её версия (Настройки → Общие → Клавиатура).
2. Включить запись экрана на телефоне (шторка → «Запись экрана»).
3. Если есть второй телефон/ноутбук — держать `adb logcat` подключённым:
   `adb logcat -s ReactNativeJS:V ReactNative:V *:E > tutak-<модель>.log`.

## Если шаг 3 или 5 FAIL (клавиатура/фокус)

Это не чинится «на глаз». Для root cause нужны все пять: (a) видео с
момента открытия экрана, (b) модель + Android + клавиатура + её версия,
(c) logcat за минуту вокруг события, (d) воспроизводится ли с **Gboard**
(поставить из Play, переключить, повторить шаг), (e) воспроизводится ли
после отключения «Автозаполнение» (Настройки → Общие → Автозаполнение →
Нет). Пункт (d) отделяет баг приложения от бага прошивки клавиатуры.
