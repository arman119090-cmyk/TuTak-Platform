# Apple Developer Program: что выбрать владельцу

Дата: 19.09.2026. Решение — за владельцем; здесь только факты и
последствия для TuTak.

## Зачем вообще

Без членства в Apple Developer Program ($99/год) нельзя: подписать
сборку для iPhone, установить её на физический iPhone (даже свой),
загрузить в TestFlight, подать в App Store. Сборка для iOS Simulator уже
есть (см. `docs/IOS_BOOTSTRAP_REPORT_2026-09-19_RU.md`) — она этого не
требует, но на телефон не ставится.

## Два варианта

| | Company / Organization | Individual |
|---|---|---|
| Кто владелец | юридическое лицо | физическое лицо |
| Что нужно | **D-U-N-S номер** организации (бесплатно, Dun & Bradstreet; получение — от нескольких дней до 2–3 недель), подтверждение полномочий подписанта, сайт/юр. документы | Apple ID с двухфакторной защитой, паспорт/удостоверение для проверки личности |
| Срок до рабочего аккаунта | обычно 1–4 недели (D-U-N-S + проверка Apple) | обычно 1–3 дня |
| Seller name в App Store | название компании (например, «TuTak LLC») | **имя и фамилия человека** — так увидят все пользователи App Store |
| Команда | несколько разработчиков с ролями, App Store Connect Users | один человек, ключи и сертификаты только у него |
| Перенос приложения | компании между собой — стандартная процедура | с Individual на Organization — возможен (App Transfer), но с оговорками и потерей части метрик; лучше сразу решить |
| Юридическая сторона | договоры с Apple подписывает организация | договоры подписывает физлицо, ответственность на нём |

## Что важно именно для TuTak

- Приложение финансовое (баллы, оплата). Для доверия пользователей и для
  App Review имя продавца «TuTak LLC» выглядит лучше, чем имя частного
  лица, и соответствует политике конфиденциальности, где оператор —
  организация.
- Если у компании уже есть D-U-N-S (он нужен и для других сервисов) —
  Organization без потери времени.
- Если пилот нужен быстро и D-U-N-S ещё нет: Individual за 1–3 дня даёт
  TestFlight сразу; позже App Transfer на аккаунт компании.

## После оформления (техническая часть, 30 минут)

1. На ноутбуке, войдя в Apple-аккаунт:
   `cd apps/mobile && npx eas-cli@latest credentials --platform ios` →
   EAS создаст сертификат и provisioning profile; для `preview-ios`
   добавить UDID iPhone.
2. GitHub → Actions → «Build iOS» → профиль `preview-ios` (на iPhone) или
   `production-ios` (TestFlight).
3. APNs-ключ (push) — EAS предложит создать при первой сборке с
   `expo-notifications`; без него приложение работает, уведомления не
   приходят.
4. App Store Connect → создать приложение с bundle `am.tutak.app` →
   вписать `ascAppId` в `apps/mobile/eas.json` → `eas submit`.

Ничего из этого нельзя сделать без п. 0 — аккаунта.
