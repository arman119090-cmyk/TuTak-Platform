# Редизайн приложения — что нужно принести

Задание владельцу продукта по присланным скриншотам (светлая тема, фото
попугая, экраны «Главная» и «Карта»). Ничего из этого ещё не реализуется —
список того, что нужно собрать, прежде чем можно начинать перекраску.
Структура экранов (низ: Главная / Карта / QR / Кошелёк / Профиль) уже
совпадает с тем, что построено сейчас — значит переделывать нужно только
внешний вид, не архитектуру.

## 1. Изображения попугая (обязательно)

В коде сейчас Джако нарисован программно — простыми векторными фигурами.
На скриншотах — фотореалистичное изображение. Векторный рисунок такое не
может повторить, нужны готовые файлы.

Найдено минимум три разных места, где попугай выглядит по-разному:

- [ ] **Круглый аватар** в шапке — крупный план головы/плеч, для круглой
      рамки.
- [ ] **Крупная иллюстрация на карточке баланса** — попугай на зелёном
      градиенте, ближе к анфас, с прозрачным фоном (без него будет виден
      прямоугольник вокруг птицы поверх зелёного).
- [ ] **Поза в промо-баннере** — попугай рядом с монетами, другая поза,
      тоже с прозрачным фоном.

Формат: PNG с прозрачностью (или похожий, лишь бы был альфа-канал), в
высоком разрешении — телефоны с retina-экраном показывают изображение в
2–3 раза крупнее его логического размера, низкое разрешение будет
выглядеть размыто. Если это иллюстрация, а не фото — нужны права на неё
или исходник от того, кто её рисовал.

## 2. Источник дизайна (обязательно для точного попадания)

Один из двух вариантов:

- [ ] **Ссылка на Figma** (доступ на просмотр достаточно) — самый быстрый
      путь, там уже есть точные цвета, отступы, шрифт.
- [ ] **Или вручную, если Figma нет:**
  - [ ] точные цвета зелёного градиента (два оттенка или один цвет с
        затемнением?);
  - [ ] цвет красной/оранжевой плашки с процентом бонуса на карточках
        партнёров;
  - [ ] название и начертания шрифта (или подтверждение, что это системный
        шрифт телефона, тогда ничего присылать не нужно);
  - [ ] если шрифт платный/лицензируемый — сам файл шрифта или
        подтверждение права его использовать.

## 3. Баннер «двойные бонусы x2» — это не картинка, это функция

На скриншоте это выглядит как один баннер, но на самом деле это акции
(промо-кампании) — то, чего в приложении нет вообще ни в каком виде. Чтобы
это заработало, а не просто было нарисовано, нужны ответы:

- [ ] Кто создаёт акцию — только админ платформы, или партнёр тоже может
      сам предложить акцию у себя?
- [ ] Акция — на всех партнёров сразу или на одного конкретного (как в
      примере — «на всех станциях FastCharge»)?
- [ ] Есть ли конец срока действия (на скриншоте — «только сегодня до
      23:59») — задаётся вручную при создании, или у акций всегда
      фиксированный срок?

Если пока не готовы отвечать — можно временно поставить экран без баннера,
это не блокирует остальную перекраску.

## 4. Мелкое, но заметное несоответствие между двумя скриншотами

На «Главной» переключатель языка — выпадающий список «RU ⌄». На «Карте» —
три вкладки «Հայ / RU / EN» рядом. Это два разных способа показать одно и
то же. Уточнить, какой из них верный (или оба к месту — один компактный
для главной, второй крупный для карты) — намеренно или недосмотр при
подготовке макета.

## Что НЕ нужно приносить

Иконки (лупа, колокольчик, слайдеры, стрелка, шестерёнка) — этого в
библиотеке иконок, которой уже пользуется приложение, достаточно, повторять
пиксель-в-пиксель не нужно, будет использован ближайший подходящий значок.
