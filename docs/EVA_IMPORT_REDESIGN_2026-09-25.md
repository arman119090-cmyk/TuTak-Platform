# Прототип сайта EVA Import в стиле Mercedes-Benz — 25.09.2026

## 1. Задание

«Я хочу, чтобы сайт Eva Import был таким же, как сайт Мерседес»: переделать
evaimport.com по образцу сайта Mercedes-Benz. Это продолжение разбора из
`docs/EVA_IMPORT_MERCEDES_SITES_2026-09-25.md`.

## 2. База

- Ветка: `claude/eva-mercedes-websites-9dp4yy`
- От коммита с первым отчётом (разбор сайтов), родитель — `369eda1`.

## 3. Что сделано

- Прототип новой главной страницы EVA Import, одна страница HTML + CSS + немного JS.
  - Опубликован (приватно): https://claude.ai/artifact/Bn3QLkL4hakWqaJmWdMvFa
  - Исходники: `docs/eva-import-prototype/index.html`, фото — `docs/eva-import-prototype/img/`
    (9 файлов, 1,2 МБ; фото взяты с evaimport.com и пережаты до 1200–1800 px).
- Стилистика по мотивам Mercedes-Benz, какой я её знаю: чёрная шапка с логотипом по
  центру; полноэкранное фото с крупным заголовком с засечками; белые разделы с
  большими фото; вкладки модельного ряда (здесь — по стране: Китай / ОАЭ / США);
  карточки «модель — характеристики — от $»; синяя кнопка действия; чёрный блок
  «автомобиль месяца» (Mercedes-AMG); строгий футер.
- Контент взят только с текущего сайта Eva: 6 машин, цены и страны (сопоставлены
  по `id` в коде их сайта — теперь это проверено, а не выведено по порядку),
  6 шагов импорта, сроки доставки, цифры 3000+ / 98% / 3 страны, телефон, адрес.
- Убраны «американские» хвосты шаблона: EST, EPA/DOT, «Inc.».
- Фильтр по странам работает; «Запросить» подставляет модель в форму.
- Форма заявки в прототипе ничего не отправляет (так и написано на странице).
- Логотип, название и эмблема Mercedes-Benz на сайте не используются — взят только
  стиль. Копировать фирменные элементы чужого бренда нельзя юридически.

## 4. Что НЕ сделано

- **Сайт Mercedes я так и не видел** (www.mercedes-benz.am блокируется окружением).
  Стиль воспроизведён по общему знанию их дизайна, а не по живому образцу.
- **Рабочий сайт evaimport.com не изменён.** Его исходников нет ни в одном доступном
  репозитории (проверено `list_repos`: TuTak-Platform, auto-parts-store, cash-out).
- Только русский язык. Переключатель ՀՅ / RU / EN нарисован, но не работает.
  На старом сайте было 4 языка.
- Нет отправки заявок (на старом — через Web3Forms), нет страниц отдельных машин и
  галерей, ссылки футера ведут только на разделы страницы.
- Цифры 3000+ и 98% перенесены со старого сайта без проверки.
- **Мои ошибки:** в первой версии я дописал от себя детали, которых нет на их сайте:
  «морем до Грузии, далее автовозом», «аукционы и дилеры», «прошёл инспекцию до
  отправки», часы 9:00–20:00. До публикации удалил, часы вернул как у них
  (8:00–20:00). Шрифты Google в локальном скриншоте не загрузились (сертификат
  прокси), поэтому оформление с нужными шрифтами проверено только на опубликованной
  странице — и то не мной, см. UNVERIFIED.

## 5. Чем доказано

- Headless Chromium, локальный файл: ширина 1366 px → scrollWidth 1366; ширина 400 px →

- Один скриншот десктопной версии просмотрен: все 6 карточек, шаги, цифры, форма и
  футер на месте. По нему поправил ленивую загрузку фото в чёрном блоке и размер
  заголовка.
- Публикация прошла успешно (Version 1).
