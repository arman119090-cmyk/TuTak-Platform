## 3. Что сделано

Сайт на Next.js 15 (JavaScript) на трёх языках: `/ru`, `/hy`, `/en`. Язык по
умолчанию выбирается по браузеру, если язык не распознан — русский.

| Страница | Содержимое |
|---|---|
| Главная | Первый экран с AMG, коллекция (лента с фильтром по странам), автомобиль месяца, категории запчастей, 6 шагов импорта, сроки, заявка |
| `/cars` | Каталог 6 машин с фильтром Дубай / США / Китай |
| `/cars/<slug>` | Галерея всех фото с их сайта (24 фото + видео Avatr), характеристики, срок доставки, заявка на машину, «другие автомобили» |
| `/parts` | Магазин: поиск по названию на всех языках, артикулу и OEM-номеру (без учёта пробелов и дефисов), фильтры по марке, категории и наличию. Пока пусто — показан экран «Каталог наполняется» |
| `/parts/<slug>` | Страница товара: цена в драмах, наличие, количество, «в корзину» |
| `/cart` | Корзина (хранится в браузере), изменение количества, итог, оформление заказа |
| `/import` | Форматы работы, шаги, сроки, из чего складывается цена, заявка |
| `/contact` | Телефон, адрес со ссылкой на Google Maps, часы работы, форма |

- **Заявки и заказы** (запрос машины, подбор по VIN, заказ, обращение) уходят на
  `/api/lead`. Сервер проверяет телефон, VIN и длину полей, отсекает ботов (скрытое поле
  и лимит 5 заявок за 10 минут с одного адреса). Сумму заказа сервер **пересчитывает по
  каталогу**, а не берёт из браузера. Дальше отправляет менеджеру в Telegram и/или на
  почту через Web3Forms — так заявки уходили и на их старом сайте.
- Если канал не настроен, покупатель видит «не удалось отправить, позвоните» и телефон.
  Ложного «отправлено» не бывает.
- SEO: заголовки и описания для каждой страницы, sitemap.xml, robots.txt, разметка
  schema.org для машин (Car) и запчастей (Product), языковые альтернативы.
- `data/parts.json` — сюда завтра лягут запчасти; формат описан в README.
- `render.yaml` — конфигурация для хостинга Render (не развёрнуто).
- `.env.example` — какие настройки нужны.
- Файлы: `app/` (страницы и API), `components/`, `lib/` (i18n, parts, leads, catalog),
  `data/` (site, cars, parts.json), `public/cars/` (фото, 21 МБ), `tests/`.

## 4. Что НЕ сделано

- **Сайт не выложен в интернет.** Нужны ваше согласие, хостинг и домен (см. вопросы).
- **Заявки пока никуда не приходят:** не настроены Telegram-бот и почта. Пока их нет,
  на рабочем сайте форма будет показывать ошибку.
- **Запчастей в каталоге нет** — ждём завтрашний список.
- **Онлайн-оплаты нет:** заказ = заявка, менеджер перезванивает.
- **Условия, которые я не знаю и поэтому не писал:** способы оплаты, стоимость и зона
  доставки, гарантия, возврат. Выбор при заказе — только «самовывоз / доставка».
- Нет страниц «Политика конфиденциальности» и «Условия». Под формами есть только
  строка о согласии на обработку данных — юридически это надо проверить.
- Нет админки: запчасти и машины правятся в файлах данных, после каждой правки сайт
  пересобирается. Для завтрашнего списка это нормально, для ежедневной работы
  менеджера — нет.
- Цифры 3000+ и 98% по-прежнему взяты со старого сайта и не проверены.
- Видео Avatr весит 16 МБ, я его не сжимал: ffmpeg в окружении нет.
- **Мои ошибки и тупики:**
  - Нужную версию TypeScript поставить не дали: команду заблокировали правила
    окружения. Перешёл на JavaScript, но в `package.json` остались неиспользуемые
    devDependencies (typescript 7, @types/*). Сайту они не мешают, но это мусор.
    Удалять их не стал, потому что пришлось бы снова ставить пакеты.
  - Скрипт раскладки фото сначала тоже заблокировали как «разрушительный». Проверил,
    что папки `public` не существует, и повторил с явным запретом перезаписи.
  - Первая версия давала ошибку гидратации React (#418) на армянских страницах: Node и
    Chromium по-разному форматируют числа в локали `hy-AM`. Нашёл при проверке, заменил
    форматирование своим.
  - Подсказка «укажите телефон» не пропадала после исправления номера, а в сетке
    запчастей пустые ячейки были серыми. Увидел на скриншотах и исправил.
  - Дважды убил собственную команду через `pkill -f`: шаблон совпал с самой командой.
  - Черновые тексты снова содержали выдуманные условия («оплата при получении»,
    «доставка в регионы», «оригинальные запчасти»). Убрал до коммита.
  - При 404 на несуществующих машинах и запчастях Next пишет в лог `NoFallbackError`.
    Ответ правильный (404), но лог засоряется — не исправлял.
