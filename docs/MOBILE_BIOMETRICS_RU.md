# Добровольная биометрическая блокировка TuTak

Функция выключена по умолчанию. Настройки → Безопасность → Face ID / вход по
отпечатку. Перед включением есть объяснение и явное согласие; затем ОС проверяет
биометрию. SMS/пароль сохраняются. На неподдерживаемых устройствах и в браузере
переключатель не предлагается. Android требует сильную биометрию, а не обычную
разблокировку по фотографии.

Это локальная блокировка уже авторизованного приложения, не новая серверная
аутентификация и не подтверждение покупки. Серверные JWT/refresh и их ротация
остаются прежними. Токены по-прежнему зашифрованы штатным SecureStore; они не
становятся криптографически привязанными к каждому сканированию лица. ОС отдельно
защищает проверочное значение с requireAuthentication, привязанное к текущему
набору биометрии. Приложение не получает изображения лица или отпечатков.

После холодного запуска и возврата из background защищённые экраны недоступны
до разблокировки. Новые API-запросы блокируются, кроме выхода из сессии;
новый refresh не начинается. Уже отправленный запрос отменить на сервере нельзя.
Закрытие приложения в системном переключателе прикрывается заставкой на inactive;
надёжность снимка recent-apps должна проверяться на конкретном устройстве.

Отмена/ошибка/изменение биометрии не открывают аккаунт. Доступен выход с попыткой
отзыва сессии на сервере и обязательной локальной очисткой, затем обычный вход.
Без сети серверный отзыв не гарантирован; локальная сессия удаляется.
Поздний ответ сканирования не может открыть другой аккаунт. После выхода и нового
входа требуется снова добровольно включить биометрию.

## Проверка на телефонах — обязательна перед объявлением готовности

1. Установить новую нативную сборку поверх прежней; проверить SMS/пароль с выключенным переключателем.
2. Отменить предложение включения: функция остаётся выключенной.
3. Включить, подтвердить сканирование, свернуть и открыть приложение.
4. Отменить/провалить разблокировку: баланс и история не показываются.
5. Успешно разблокировать, затем полностью закрыть и снова открыть приложение.
6. Отключить функцию с подтверждением; повторное открытие не требует биометрии.
7. Изменить биометрию в ОС: прежняя проверка не должна открывать приложение;
   завершить сессию и войти через SMS/пароль.
8. Проверить выход и вход под другим аккаунтом, включая выход во время сканирования.
9. Проверить отсутствие персональных данных в recent-apps, safe areas, клавиатуру,
   возврат из камеры/выбора фото и разрешений геолокации.
10. iPhone с Face ID и Android с сильной биометрией проверяются отдельно.

Face ID не проверяется через Expo Go или Android APK. Нужна подписанная iOS-сборка
и физический iPhone. Модульные тесты и проверка Info.plist не заменяют эту проверку.
