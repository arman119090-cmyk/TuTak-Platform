# Отчёт: не удаётся войти в админку

## 1. Задание

«Логин и пароль админ-панели — мы не можем зайти».

## 2. База

Ветка `claude/little-joe-armenia-ecommerce-ccikt1`, от коммита `4dcb9e9`.
Результат — коммит `befbf41`.

## 3. Что сделано

### Диагностика

- В HTTP-логах Railway в 14:24 видно две попытки `POST /admin/login` с iPhone
  с нового IP. Обе вернули 200, то есть форму с ошибкой; при успешном входе
  был бы редирект. Ошибок 5xx нет.
- В 13:39 с другого IP вход проходил успешно. Значит, сервер работает, а
  введённые данные не совпали.
- Вероятные причины:
  - похожие символы в пароле `LJ-65mgv0hQlPf6mPvr`: 0 и O, l и I;
  - пробел, прилипший при копировании из чата на телефоне: пароль раньше не
    обрезался по краям.
- Какая именно причина, не установлено. Журнал входа (`AuditLog`) лежит в
  базе на Railway, а к ней у меня нет прямого доступа.

### Исправления

- `src/app/admin/login/actions.ts`: пробелы по краям пароля теперь
  отбрасываются. Email и раньше обрезался и приводился к нижнему регистру.
- `src/app/admin/users/actions.ts`: при создании администратора пароль тоже
  обрезается, чтобы не было расхождения с входом.
- `prisma/seed.ts`: добавлен флаг `ADMIN_RESET_PASSWORD=true`. На один деплой
  он ставит `ADMIN_PASSWORD` существующему владельцу. Сброс пишется в журнал
  действий.
- На Railway:
  - установлен новый пароль без похожих символов: `joe-…` (сообщён владельцу
    в чате, в файлы не записан);
  - выполнен деплой `3d550fee`, в логе есть строка
    `password of owner@example.com reset`;
  - после сброса флаг выставлен в `false`, чтобы следующий перезапуск не
    сбрасывал пароль.

## 4. Что НЕ сделано

- **Моя ошибка:** первый пароль я сгенерировал с похожими символами (0/O,
  l/I). Для ручного ввода на телефоне это неудачно.
- **Моя ошибка при локальной проверке:** запустил сид без `SEED_DEMO`, и он
  выключил демо-промокоды в локальной базе. Вернул их вручную SQL-запросом.
  На Railway это не повлияло.
- Кнопки «Сменить пароль» в админке по-прежнему нет.
- Причину неудачного входа в 14:24 точно не установил (см. диагностику).
