## 4. Что НЕ сделано / отличается от макета

- **Намеренно не перенесено**, потому что это выдуманные данные:
  рейтинги «4.9 (128)» и счётчики отзывов (звёзды показываются только при
  реальных одобренных отзывах); «Лёгкий возврат» (обещание без условий
  возврата); иконки «Длительный аромат», «Безопасен для салона» (свойства
  товара без подтверждения).
- **«MADE IN ITALY» / «Сделано в Италии»** сделаны, но показываются только
  если заявление `made-in-italy` подтверждено в админке (Заявления о бренде →
  статус «Подтверждено» + источник). Сейчас оно не подтверждено — значков
  нет.
- Цены оставлены демо (2 500–3 200 ֏), а не 4 900 AMD из макета — цена из
  макета тоже не подтверждена.
- Фото «приборная панель с персонажами» и фон «Ереван + Арарат» из макета
  не использованы: фото — низкого разрешения; вместо фона нарисовано своё
  векторное небо с Араратом.
- Реквизиты сцены с «реквизитом» у каждого аромата (вишня, цветок, листья)
  не сделаны.
- Little Joe собран из фрагмента макета размером ~180×250 px: при увеличении
  картинка мягкая. Нужны исходные фото в высоком разрешении.
- У Little Cat виден тонкий край прозрачного блистера — белый кот на белом
  фоне автоматически не отделяется. Нужно фото кота без упаковки.
- Логотип — шрифтовой вордмарк, не официальный файл логотипа.

**Мои ошибки по ходу**:
- Первая нарезка Joe обрезала правую руку, вторая оставила выемку на голове от
  закраски значка — переделал на маску по цвету.
- Первая попытка с котиком (зеркальная симметрия) захватила весь блистер —
  откатил, применил BiRefNet.
- Правки больших файлов через `sed`/скрипты несколько раз давали громоздкие
  диффы; переключился на точечные правки.
- Во время работы упал основной Postgres dev-окружения (перезапуск
  контейнера) — поднял заново.

## 8. Дополнение: «как можно премиальнее»

Сделано:

  плашка и метка на странице товара); чёрная плашка демо заменена тонкой

  (анимация выключается при prefers-reduced-motion).
- Заголовки секций с фирменной «кикер»-линией, крупнее и плотнее.
- Новая секция «Познакомьтесь с семьёй» — высокие плитки 5 персонажей в
