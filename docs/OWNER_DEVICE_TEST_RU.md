# Проверка на телефоне владельца — один короткий прогон

Сборки: см. раздел «ANDROID RC» / «iOS SIMULATOR RC» в
`docs/FINAL_INTEGRATION_2026-09-19_RU.md`. Samsung и Xiaomi — по одному
проходу каждый. По каждому пункту: PASS / FAIL + фото при FAIL.

| # | Что сделать | Что ожидается |
|---|---|---|
| 1 | Установить, запустить | светлый splash, экран входа, нет тёмных вспышек |
| 2 | Регистрация по номеру | код приходит СМС (если нет — это Viva-туннель, не приложение; см. `docs/SMS_STATUS_CHECK_2026-09-19.md`) |
| 3 | Вход, поле ввода | клавиатура открывается, фокус не прыгает, поля не мигают |
| 4 | Home | hero с балансом, «Сканировать QR», две быстрые кнопки |
| 5 | Баланс | цифры читаются, бар и легенда на месте |
| 6 | QR CTA | открывает камеру / запрос разрешения с понятным текстом |
| 7 | Карусель «От партнёров TuTak» (demo-сборка) | 3 карточки, вторая видна справа, свайп «прилипает» к карточке, нет автопрокрутки |
| 8 | Тап по карточке | открывается страница партнёра, есть «Показать на карте» |
| 9 | Кошелёк | одна колонка без карточек, списки читаются |
| 10 | Настройки | группы строк, язык переключается |
| 11 | Армянский | Home и Кошелёк по-армянски; даты «Այսօր», «17 սեպ, 2026 թ.» — не «Sep 17» |
| 12 | Нижняя навигация по-армянски | «Դրամապանակ» целиком, одна строка, не касается «Գլխավոր» |
| 13 | fontScale 1.3 (Настройки телефона → Размер шрифта) | Home, Кошелёк, Настройки без обрезания; кнопки растут по высоте |
| 14 | Нижняя навигация | над системной панелью/жестом, не перекрыта |

Если повторится баг клавиатуры (п. 3) — не начинать диагностику заново:
есть `docs/ANDROID_KEYBOARD_*` и диагностическая сборка
(`diagnostic` профиль), которые уже собирали трассу.
