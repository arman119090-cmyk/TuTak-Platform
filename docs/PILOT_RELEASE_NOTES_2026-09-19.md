## Что клиент и партнёр могут делать

- Регистрация и вход по SMS-коду (Viva) и паролю; сброс пароля по SMS.
- Поиск партнёров, QR ветки, DIRECT-покупка: клиент вводит сумму →
  показывает код → кассир подтверждает в Partner-панели → кешбэк в
  кошельке (сначала «ожидает», затем доступен по правилу партнёра).
- Реферальный код: награда рефереру при первой подтверждённой покупке.
- Возврат покупки партнёром (полный/частичный), с автоматическим
  откатом кешбэка и реферальной награды; двухчеловечное одобрение
  refund-request.
- Расчёты партнёрам (draft → ready → approve → paid) в Admin;
  «Сообщить о проблеме» в Partner-панели.
- Удаление аккаунта клиентом (пароль, 30 дней grace).

## Что в пилоте ВЫКЛЮЧЕНО и почему

| Функция | Состояние | Почему |
|---|---|---|
| Оплата через Idram (`TUTAK_PSP_ENABLED`) | выключено | нет подтверждения провайдера, нет `ALERT_WEBHOOK_URL`; код запускает маршрут только при флаге + всех credentials |
| Возвраты через PSP (`PSP_REFUNDS_ENABLED`) | выключено | зависит от Idram |
| Пополнение prepaid (`CUSTOMER_PREPAID_TOPUP_ENABLED`) | выключено | не нужно пилоту |
| Карточные платежи (`CARD_PAYMENTS_ENABLED`) | модуль не смонтирован | legacy |
| EV-зарядка live, роуминг OCPI | нет credentials | вне пилота |
| Биометрическая блокировка (PR #52) | не влито | не проверено на устройстве |

Деньги в пилоте **не проходят через TuTak**: клиент платит партнёру у
кассы, TuTak учитывает кешбэк и расчёт партнёру.

## Известные ограничения

- Смены номера телефона нет; потеря SIM = новый аккаунт (runbook §6).
- Лимит OTP на один IP-адрес: 60 кодов/час (переопределяется
  `OTP_IP_ISSUANCE_PER_HOUR` без деплоя — для мероприятия на одном wifi
  поставить 300 заранее).
- Глобальный rate limit 120 запросов/мин на IP.
- Бэкапа production-базы **нет**, пока Арман не включит PITR (DR runbook).
- Внешний мониторинг (`.github/workflows/uptime.yml`) заработает только
  после попадания в `main` и добавления secret `ALERT_WEBHOOK_URL`.

## Условия остановки пилота (STOP)

1. `tutak_ledger_imbalance_amd ≠ 0` или алерт `reconciliation.drift`.
2. Покупка подтверждена дважды или кешбэк начислен дважды (§2 pilot-verify.sql).
3. `/health/ready` ≠ 200 дольше 10 минут.
4. Любой `outbox.dead-letter`.
5. Кассир может подтвердить покупку без кода клиента.
6. SMS не доходят > 10 % регистраций за час.
