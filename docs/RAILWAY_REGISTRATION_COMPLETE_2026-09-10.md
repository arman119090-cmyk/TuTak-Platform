# Регистрация по СМС работает целиком — 10.09.2026

## Что подтверждено

Полный сквозной сценарий на боевом Railway-деплое, на реальном телефоне:

| шаг | результат |
|---|---|
| `POST /v1/auth/register/request-otp` | `{"data":{"success":true}}` |
| журнал сервера | `otp register: code-handed-to-carrier` |
| телефон | **СМС с кодом пришла** (отправитель `Tu-Tak`) |
| `POST /v1/auth/register/verify-otp` | аккаунт создан |
| ответ | `isPhoneVerified: true`, роль `CUSTOMER`, права `WALLET_READ` + `QR_REDEEM`, выданы `accessToken` и `refreshToken` |

Это и есть исходный критерий завершения: не HTTP 200 и не `success: true`,
а реальная СМС, которой подтвердилась регистрация.

Путь целиком: приложение/curl → `tutak-api` на Railway → HTTPS+HMAC →
шлюз Contabo `217.76.49.94` → IPsec-туннель → Viva Business Hub → телефон.

## Гигиена

В процессе проверки живые `accessToken`/`refreshToken` тестового аккаунта
попали в скриншот переписки. Аккаунт тестовый, права минимальные, инстанс в
демо-режиме, access-токен живёт 15 минут; refresh-токен действует месяц.
При желании аккаунт деактивируется через `PATCH /admin/users/:id/active`.
