Два разных «READY», которые нельзя путать:

- **READY-A — реальные пользователи без денег через TuTak.** Клиент платит партнёру напрямую

  выплаты/взыскания с партнёрами по банку. Это текущая модель `main` + PR #60. Нужны этапы 0, 1, 2 (частично), 4, 5.

  Это код #64 + #65 за флагами. Нужно всё: этапы 0–5 целиком, включая договор с Idram и юридические решения.

Условные обозначения статуса: ✅ закрыто фактом · 🟡 частично / есть код, нет доказательства · ❌ не сделано · 🔒 только владелец / внешняя сторона.
