# Релиз 13 сентября 2026 — миграция и откат

Проверено на PostgreSQL 16 до выкатки, а не по памяти.

## Что меняется в базе

Ровно одна миграция:

```
20260913140000_partner_tax_id_optional
ALTER TABLE "partners" ALTER COLUMN "taxId" DROP NOT NULL;
```

Это снятие ограничения, а не изменение данных.

## Измеренные последствия

| Что | Результат |
|---|---|
| Время выполнения | **1,1 мс** |
| Перезапись таблицы | **нет** — `pg_relation_filenode` не меняется |
| Блокировка | краткая `ACCESS EXCLUSIVE` на каталог, без сканирования строк |
| Потеря данных | невозможна: столбец не трогается, только его ограничение |
| Уникальный индекс | остаётся; в PostgreSQL NULL не равен NULL, поэтому партнёров без ՀՎՀՀ может быть сколько угодно, а двух одинаковых номеров по-прежнему не будет |

Таблица `partners` маленькая (единицы строк), поэтому даже операция со
сканированием была бы незаметной.

## Откат — и его честная граница

```
ALTER TABLE "partners" ALTER COLUMN "taxId" SET NOT NULL;
```

**Пока ни одной заявки без ՀՎՀՀ нет** — откат проходит за 0,5 мс, без
перезаписи таблицы. Проверено.

**Как только появится хоть один партнёр с пустым ՀՎՀՀ** — откат
отклоняется. Дословно из проверки:

```
ERROR:  column "taxId" of relation "partners" contains null values
```

Это не сбой, а определение: нельзя вернуть ограничение, которому данные
больше не удовлетворяют. Чтобы откатиться после этого, нужно сначала
заполнить или удалить такие строки — то есть решить судьбу реальных
заявок, а это уже не техническая операция.

**Откат только кода — безопасен всегда.** Старый код никогда не пишет
NULL, а чтение столбца, ставшего необязательным, на уровне базы
корректно. Единственное расхождение: тип `PartnerDto.taxId` в старом
коде объявлен как `string`, поэтому у партнёра, заведённого новым кодом
без номера, админ-панель покажет пустое место вместо прочерка. Это не
падение.

## Практический вывод

Окно безопасного полного отката — от выкатки до первой заявки без
ՀՎՀՀ. После этого откатывается только код, а схема остаётся
расширенной. Расширение при этом обратно совместимо: старый код с ней
работает.
