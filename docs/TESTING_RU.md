# Как запустить TuTak у себя и всё протестировать

Этот документ — про то, как получить **работающее приложение на своём
компьютере** и покликать в нём всё самому: админку, кабинет партнёра,
мобильное приложение и API. Не скриншоты — настоящая система с настоящими
данными.

---

## 1. Что нужно установить

Только **Docker**. Ничего больше — ни Node, ни PostgreSQL, ни Redis.

- macOS / Windows: [Docker Desktop](https://docs.docker.com/get-docker/)
- Linux: Docker Engine + плагин Docker Compose v2

Проверить, что всё готово:

```bash
docker compose version
```

Если команда напечатала версию — можно продолжать.

> Мобильное приложение — единственная часть, которой нужен ещё Node 20+ и
> pnpm. Веб-часть и API работают только на Docker. См. раздел 6.

---

## 2. Запуск — одна команда

```bash
git clone <адрес репозитория> tutak
cd tutak
./scripts/demo-up.sh
```

Скрипт сам:

1. создаст файл `.env` со случайными секретами (в репозиторий он не
   попадает);
2. соберёт три образа — API, админка, кабинет партнёра;
3. поднимет PostgreSQL, Redis и все три приложения;
4. применит миграции базы;
5. заполнит базу демо-данными: партнёры, клиенты, зарядные станции,
   платежи, начисления бонусов, возврат, выплата и две сверки.

**Первый запуск занимает несколько минут** — собираются образы. Все
следующие запуски — секунды, Docker кеширует сборку.

Когда скрипт закончит, он напечатает адреса и логины.

### Остановить

```bash
./scripts/demo-down.sh          # остановить, данные сохранить
./scripts/demo-down.sh --wipe   # стереть базу и начать с чистого листа
```

## 4. Что смотреть в админке (http://localhost:3000)

Зайдите как `+37400000000`.

| Экран | Что там должно быть | Что можно сделать |
|---|---|---|
| **Overview** | сводка по платформе | — |
| **Users** | 8 пользователей | посмотреть роли |
| **Partners** | 4 партнёра с разными ставками бонуса и комиссии | включить/выключить партнёра |
| **Bonus adjustments** | ручное начисление/списание бонусов | начислить клиенту бонусы и увидеть их в мобильном приложении |
| **Refunds** | 7 успешных платежей и 1 отклонённый | сделать возврат — бонусы, начисленные с этого платежа, спишутся обратно |
| **Payouts** | одна выплата 20 000 AMD со статусом `paid` | заказать новую выплату партнёру |
| **Ledger** | 6 счетов, сумма по всем = 0 | нажать на счёт и увидеть все проводки; колонка «сходится» сверяет сохранённый баланс с пересчётом по проводкам |
| **Reconciliation** | две сверки: 07.08 — чисто, 08.08 — расхождение 1 250 AMD | «Clear payout block» снимает блокировку выплат с партнёра |
| **Fraud signals** | сигналы антифрода | — |
| **Audit log** | все действия с деньгами и правами | — |

**Самое интересное — экран Ledger.** Двойная запись: сумма всех счетов
всегда ноль. Сделайте возврат или выплату и вернитесь — сумма останется
нулём.

## 5. Что смотреть в кабинете партнёра (http://localhost:3001)

Зайдите как `+37477200001` (Cafe Yerevan).

| Экран | Что там должно быть |
|---|---|

| **Payment QR** | выпустить QR-счёт на сумму — его можно отсканировать мобильным приложением |
| **Earnings** | 51 272,50 AMD к выплате, дневная сверка (76 100 оборот, 1 902,50 комиссия), выплата 20 000 со статусом `paid` |

Зайдите ещё под `+37477200003` (TuTak Market) — там на экране Earnings
видно, как выглядит партнёр, которому сверка заблокировала выплаты.

## 6. Мобильное приложение

Тут Docker не поможет — Expo нужно запускать на хосте. Понадобится
Node 20+ и pnpm.

```bash
# один раз
corepack enable
pnpm install

# узнать свой IP в локальной сети:
#   macOS/Linux:  ipconfig getifaddr en0   или   hostname -I
#   Windows:      ipconfig
API_BASE_URL=http://192.168.1.50:4000/v1 pnpm --filter @tutak/mobile start
```

Дальше — установите **Expo Go** на телефон и отсканируйте QR из терминала.
Телефон и компьютер должны быть в одной Wi-Fi сети.

> `localhost` в мобильном приложении указывает на сам телефон, поэтому
> нужен именно IP компьютера в локальной сети.

Чтобы API принимал запросы с телефона, добавьте этот адрес в `CORS_ORIGINS`
в `.env` и перезапустите: `docker compose up -d api`.

**Сценарий для проверки целиком:**

1. В кабинете партнёра (`+37477200001`) откройте **Payment QR** и выпустите
   счёт, например на 5 000 AMD.
2. В мобильном приложении войдите как `+37477100001`, откройте сканер и
   отсканируйте этот QR.
3. Оплатите — можно частично списать бонусы.
4. В приложении на экране кошелька увидите новые начисленные бонусы.
5. В кабинете партнёра операция появится в **Transactions**.
6. В админке в **Ledger** появятся новые проводки, и сумма по счетам
   останется нулём.

## 7. Проверить API напрямую

Swagger: http://localhost:4000/docs

Или из терминала:

```bash
TOKEN=$(curl -s -X POST http://localhost:4000/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"phone":"+37400000000","password":"TuTakDemo-2026!","deviceId":"cli"}' \
  | python3 -c 'import sys,json;print(json.load(sys.stdin)["data"]["tokens"]["accessToken"])')

curl -s http://localhost:4000/v1/admin/ledger/accounts \
  -H "Authorization: Bearer $TOKEN"
```

Здоровье системы:

```bash
curl -s http://localhost:4000/health/ready
# {"data":{"status":"ok","checks":{"database":"ok","redis":"ok"}}}
```

## 8. Если что-то не так

| Симптом | Что делать |
|---|---|
| `Cannot connect to the Docker daemon` | запустите Docker Desktop |
| Порт занят (3000/3001/4000/5432/6379) | остановите то, что его занимает, либо поменяйте порт в `docker-compose.yml` |
| Экраны пустые | демо-данные не засеялись: `docker compose logs api`, затем `./scripts/demo-down.sh --wipe && ./scripts/demo-up.sh` |
| Не пускает в кабинет партнёра | вы заходите админом — нужен `+37477200001` |
| Сборка падает на `pnpm install` | нет интернета у Docker; проверьте прокси/VPN |
| Хочу начать заново | `./scripts/demo-down.sh --wipe && ./scripts/demo-up.sh` |

Логи:

```bash
docker compose logs -f api       # backend
docker compose logs -f admin     # админка
docker compose ps                # что вообще запущено
```

## 9. Запуск без Docker

Если Docker недоступен, есть путь через локально установленные PostgreSQL и
Redis:

```bash
./scripts/dev-setup.sh
# затем, каждый в своём терминале:
pnpm --filter @tutak/api dev
pnpm --filter @tutak/admin dev
pnpm --filter @tutak/partner dev
```

Демо-данные в этом случае засеваются вручную:

```bash
cd apps/api
pnpm run build
SEED_ADMIN_PASSWORD='TuTakDemo-2026!' node dist/scripts/seed-baseline.js
TUTAK_DEMO=1 DEMO_PASSWORD='TuTakDemo-2026!' node dist/scripts/seed-demo.js
```

## 10. Чего здесь нет

Честно, чтобы не было сюрпризов:

- **Настоящих денег.** Платёжный провайдер — песочница
  (`SandboxPspAdapter`). Карты не списываются, банк ничего не переводит.
  Токен `tok_decline_insufficient_funds` всегда даёт отказ — так сделан
  отклонённый платёж в демо-данных.
- **SMS.** Коды подтверждения не отправляются, пока не заполнены
  `SMS_*` в `.env`. Демо-клиенты созданы уже подтверждёнными.
- **Публичного адреса.** Всё работает на `localhost` вашей машины. Чтобы
  открыть доступ извне, нужен хостинг — см. `docs/DEPLOYMENT.md`.
- **Статических QR магазина.** Тип `STATIC_MERCHANT` намеренно отключён:
  он позволял начислять бонусы за платёж, которого не было. Работают
  одноразовые счета `DYNAMIC_INVOICE`.
