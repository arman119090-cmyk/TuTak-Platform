### 3.2 Где код не выполнял обещанного — исправлено в коде

1. **Координаты попадали в журнал сервера.** `RequestContextMiddleware`
   клал в контекст `req.originalUrl` целиком, а `StructuredLogger` пишет
   этот путь в каждую строку лога запроса; для `/partners/nearby?lat=…&lng=…`
   это положение человека. Теперь в контекст попадает путь без строки
   запроса. Тест: `request-context.spec.ts` «never carries the query string».
2. **При обезличивании в журнале безопасности оставались IP и User-Agent.**
   `anonymize()` теперь обнуляет их во всех записях этого человека; сами
   события остаются. Тест: «takes the address and the device out of the
   security journal, and keeps the events».
3. **Фото профиля оставалось в хранилище.** Ссылка на аватар не обнулялась,
   объекты в S3 не удалялись. Теперь `avatarAssetId` обнуляется, ассеты
   помечаются `REVOKED` в той же транзакции, объекты удаляются после
   коммита (best effort, с логированием ключа при неудаче). Тест: «removes
   the profile photo from storage, not only from the profile».
