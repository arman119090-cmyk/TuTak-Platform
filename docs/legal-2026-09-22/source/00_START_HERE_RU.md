# Юридический пакет TuTak для приложения

Подготовлен 22 сентября 2026 года. Версия проекта документов 0.9. Статус — проекты для согласования, НЕ опубликованные условия.

Пакет содержит полноценные проекты пользовательских текстов на русском и армянском языках, уведомления и согласия при регистрации, отдельную заготовку условий оплаты через PSP и задание разработчику. Основной комплект описывает DIRECT_PARTNER: деньги за покупку получает партнёр, TuTak ведёт бонусную программу. Пополняемый денежный кошелёк этим пакетом не вводится.

## Как прочитать и использовать

Откройте INDEX.html — все документы собраны в одном файле с оглавлением. Исходные тексты находятся в public/ru и public/hy; внутренние пояснения — в internal. Файлы public являются проектами для будущей публикации, а не подтверждением того, что соответствующие процессы уже реализованы.

Нельзя публиковать пакет, пока остаются поля {{...}}, не утверждены бизнес-параметры и не проверено соответствие приложения текстам. Дата подготовки не является датой вступления пользовательских условий в силу. Обозначения «проект» снимаются только после согласования.

## Что подготовлено

1. Условия использования приложения.
2. Политика обработки персональных данных.
3. Правила бонусов, отмен и возвратов.
4. Согласие на необходимую обработку данных и отдельные добровольные согласия.
5. Порядок закрытия аккаунта и обращений по данным.
6. Условное дополнение об оплате конкретной покупки через PSP — не для текущей публикации.
7. Редакторская и правовая проверка, источники, вопросы владельцу и юристу.
8. Техническое задание Claude для внедрения документов и доказательств согласия.
9. Формы обращений пользователя.

## Что этот пакет не заменяет

Пакет не является заключением армянского адвоката о законности денежной модели. Не заменяет договоры TuTak с партнёрами, Idram и поставщиками обработки данных, бухгалтерскую политику, фискальные документы и внутренние процедуры информационной безопасности. Конкретные вопросы к таким документам перечислены в internal/07_APPROVAL_AND_SOURCES_RU.md.

Включение оплаты через PSP требует отдельной проверки роли TuTak, продавца и получателя денег. Само наличие merchant API этого не разрешает. Stored value, cash-out, кредиты, платные подписки, доставка и live EV не входят в основную редакцию.

## Предложенные условия которые ещё должен утвердить владелец

Для проекта предложены: самостоятельная регистрация с 18 лет; отсутствие отдельной платы за регистрацию; отсутствие продажи и обналичивания бонусов; сохранение уже заработанных прав при изменениях правил; отсутствие автоматического денежного долга клиента из-за корректировки бонусов. Это предложения условий договора, а не описание обязательных возрастных или тарифных требований закона. Сроки бонусов, отложенных начислений и хранения данных оставлены явными полями для заполнения.

Русская и армянская редакции подготовлены параллельно. Армянский текст также является проектом и требует окончательной проверки юристом, владеющим армянским юридическим языком. Английскую локализацию приложения нельзя направлять на неподготовленные английские условия: до перевода пользователь должен осознанно выбрать доступный язык.
