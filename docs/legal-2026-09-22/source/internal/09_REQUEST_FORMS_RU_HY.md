# Формы обращений пользователя

Проекты вспомогательных форм. Не являются обязательной единственной формой обращения и не заменяют установленную законом подпись или реквизиты формального запроса.

## Обращение по покупке на русском

Кому: [продавец / Оператор TuTak]. Покупка: [номер, дата, партнёр]. Товары или услуги: [перечень]. Требование: [отмена / отказ от дистанционного договора / возврат из-за недостатка / исправление бонусов / другое]. Основание и обстоятельства: [описание; при законном отказе без причины объяснять причину не требуется]. Реально уплачено: [сумма и способ]. Применены бонусы: [сумма]. Уже возвращено: [сумма]. Связь для ответа: [контакт]. Приложения: [перечень]. Дата: [дата]. Прошу подтвердить получение обращения.

## Գնման վերաբերյալ դիմում

Ում՝ [վաճառող / TuTak Օպերատոր]։ Գնում՝ [համար, ամսաթիվ, գործընկեր]։ Ապրանքներ կամ ծառայություններ՝ [ցանկ]։ Պահանջ՝ [չեղարկում / հեռակա պայմանագրից հրաժարում / թերության պատճառով վերադարձ / բոնուսների ուղղում / այլ]։ Հիմք և հանգամանքներ՝ [նկարագրություն. առանց պատճառի օրինական հրաժարման դեպքում պատճառ բացատրել պետք չէ]։ Փաստացի վճարված՝ [գումար և եղանակ]։ Կիրառված բոնուսներ՝ [գումար]։ Արդեն վերադարձված՝ [գումար]։ Պատասխանի կապ՝ [կոնտակտ]։ Հավելվածներ՝ [ցանկ]։ Ամսաթիվ՝ [ամսաթիվ]։ Խնդրում եմ հաստատել դիմումի ստացումը։

## Первичное обращение по данным

«Прошу [предоставить сведения / исправить / прекратить обработку / отозвать конкретное согласие / закрыть аккаунт]. Аккаунт: [достаточный идентификатор]. Категории или цель: [указать]. Контакт для безопасного ответа: [контакт]. Прошу сообщить, какие сведения и форма подтверждения необходимы для рассмотрения моего запроса по закону». Не вставлять пароль, OTP, PIN или копию паспорта без обоснованной необходимости.

## Տվյալների վերաբերյալ նախնական դիմում

«Խնդրում եմ [տրամադրել տեղեկություններ / ուղղել / դադարեցնել մշակումը / հետ կանչել կոնկրետ համաձայնությունը / փակել հաշիվը]։ Հաշիվ՝ [բավարար նույնացուցիչ]։ Կատեգորիաներ կամ նպատակ՝ [նշել]։ Անվտանգ պատասխանի կապ՝ [կոնտակտ]։ Խնդրում եմ հայտնել, թե օրենքով դիմումի քննության համար ինչ տվյալներ և հաստատման ձև են անհրաժեշտ»։ Մի ներառեք գաղտնաբառ, OTP, PIN կամ անձնագրի պատճեն՝ առանց հիմնավորված անհրաժեշտության։
