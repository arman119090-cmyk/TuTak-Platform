# Реестры для заполнения до публикации

Эти таблицы заполняют Оператор, разработчик и юрист совместно. После утверждения для пользователя публикуется только понятная часть без внутренних секретов. Ссылки на незаполненные таблицы недопустимы.

## Реестр обработки и сроков

Для каждой строки заполнить: конкретные поля; источник; цель; основание; обязательность; получатели; страны; начало отсчёта; максимальный срок; исключение с правовым основанием; способ удаления/обезличивания; ответственный; автоматическая проверка.

| Категория | Начало отсчёта которое нужно определить | Особое замечание |
| --- | --- | --- |
| Аккаунт и профиль | Создание / закрытие | Отделить доступ от хранения остаточных сведений |
| OTP и challenge | Выпуск / истечение | Не хранить секрет в согласиях и логах |
| Сессии | Завершение / отзыв | Удалить ненужные IP и user agent |
| Consent evidence | Выдача / отзыв / завершение отношений | Сохранять ровно нужное доказательство |
| Покупки и ledger | Дата учётного документа / отчётного периода | Конкретная норма бухгалтерии, не бессрочно |
| Refund и споры | Завершение / срок законного требования | Legal hold только обоснованного объёма |
| Audit и fraud | Событие / окончание расследования | Не считать псевдонимизацию автоматическим удалением |
| Support | Закрытие обращения | Проверить вложения и копии переписки |
| Фото профиля | Удаление фото / закрытие аккаунта | Проверить публичные URL, CDN и старые версии |
| Геолокация | Запрос / завершение сессии | Не хранить маршрут без отдельной цели |
| Push и реклама | Отзыв / logout / смена аккаунта | Suppression и очередь рассылки |
| Backups | Создание копии | Верхний срок, PITR и повторное применение удалений |

## Реестр получателей

Обязательные столбцы: бренд, полное договорное лицо, адрес/контакт, собственная роль или поручение, точные категории данных, цель, страны хранения и доступа, субподрядчики, договор, основание международной передачи, ссылка на информацию для пользователя, дата проверки. Заменять юридические лица одним словом «облако» нельзя.
