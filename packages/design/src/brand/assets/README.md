# Логотип-источник для редизайна

`tutak-logo-source.jpeg` — прислан владельцем продукта 2026-08-12, 8000×8000,
полноцветный (серый попугай, зелёно-синее кольцо, текст «TU TAK»).

Это не то же самое, что `../jako.svg` рядом — тот нарисован программно,
простыми векторными фигурами, и используется в текущей (тёмной) версии
приложения через `Jako.tsx`. Этот файл — источник для новой, светлой
версии дизайна, описанной в `docs/DESIGN_HANDOFF_RU.md`.

**Ещё не нарезан на нужные экрану кадры.** Дизайну с двух присланных
макетов (`docs/DESIGN_HANDOFF_RU.md`, пункт 1) нужны отдельные обрезки —
круглый аватар (голова крупным планом), иллюстрация на карточку баланса,
поза для промо-баннера — этот файл полноформатный логотип-эмблему, не
все три варианта сразу. Обрезка и подготовка версий под каждое место —
предстоящая работа, не сделана автоматически при сохранении.
