# TuTak — посмотреть приложение на телефоне

Это обычное Expo-приложение. Ему не нужны Docker, PostgreSQL, Redis, Prisma,
`.env`, миграции и сиды. Данные внутри — приложение никуда не ходит.

## Что делать

1. Скачайте ZIP репозитория с GitHub и распакуйте.
2. Откройте в VS Code **папку `demo`** — именно её, а не корень репозитория.
3. В терминале, находясь в этой папке:

```
npm install
npx expo start
```

4. Отсканируйте QR-код приложением **Expo Go** (Android — из Google Play).

Первая команда идёт две-три минуты и нужна один раз. Дальше — только
`npx expo start`.

## Как войти

На экране входа нажмите **«Войти в демо»**. Регистрация и пароль не нужны.

Обычная форма входа тоже работает: подойдут любой номер и любой пароль от
восьми символов. Проверять их нечему — сервера нет.

## Что внутри

Кошелёк с бонусами, история операций, начисления и списания, QR-код для
оплаты, зарядные станции с идущей сессией, приглашения друзей, уведомления,
настройки. Данные вымышленные, но живые: оплата по QR и остановка зарядки
меняют баланс, прочитанное уведомление становится прочитанным. Всё это
держится в памяти и сбрасывается при перезапуске.

## Если что-то пошло не так

**«Something went wrong» или белый экран в Expo Go.** Чаще всего это старый
кэш. Остановите сервер и запустите `npx expo start -c`.

**QR-код не сканируется.** Телефон и компьютер должны быть в одной сети
Wi-Fi. Если сеть с изоляцией клиентов (гостевая, офисная), помогает
`npx expo start --tunnel`.

**`npx expo start` не находится.** Нужен Node.js 20 или новее —
`node --version` покажет установленную версию.

**Камера в разделе «Сканировать QR».** Expo Go спросит разрешение; без него
экран останется чёрным. Сканировать всё равно нечего — оплату можно
посмотреть через «Мой QR-код».

## Чем это отличается от настоящего приложения

Ничем, кроме источника данных. Экраны, навигация, состояние, обработка
ответов — тот же код, что и в `apps/mobile`. Подменён только транспорт:
`src/data/api/mockAdapter.ts` отвечает вместо сервера. Поэтому то, что вы
видите здесь, — это действительно поведение приложения, а не отдельный макет.

Чего здесь нет: настоящих денег, настоящих SMS, настоящей регистрации и
push-уведомлений на устройство.

## Для разработчика

Эта папка **сгенерирована** и правки в ней перезатрутся. Менять нужно
`apps/mobile` и `packages/*`, а затем выполнить в корне репозитория:

```
scripts/build-demo-app.sh
```

CI перегенерирует и сравнит: если приложение изменилось, а `demo/` — нет,
сборка упадёт. Это единственное, что не даёт копии тихо разойтись с
оригиналом.
