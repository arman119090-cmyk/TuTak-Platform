## 1. Цель

Премиальный сайт-визитка строительной компании ElGo (Ереван, Армения). Задача сайта — вызывать доверие у частных и корпоративных заказчиков и собирать заявки. Стиль: сдержанный, «архитектурный», как у девелоперов премиум-класса. Никаких шаблонных «строительных» штампов (оранжевые каски, стоковые чертежи, градиенты, эмодзи).

**Этап 1 (MVP), делаем сейчас:** одна длинная главная страница на трёх языках + страница политики конфиденциальности + рабочая форма заявки.
**Этап 2 (позже, не делать сейчас):** отдельные страницы проектов и направлений. Но структуру данных для проектов заложить сразу, чтобы добавление проекта = добавление одного файла.

## 4. Технологии

- **Astro** (последняя стабильная версия), TypeScript.
- Стили: обычный CSS с CSS-переменными (дизайн-токены ниже). Без UI-китов.
- Встроенная i18n Astro: `/hy/`, `/ru/`, `/en/`. Язык по умолчанию — **армянский** (`/` → `/hy/`). Все тексты — в файлах словарей `src/i18n/{hy,ru,en}.json`, не в разметке.
- Проекты — Astro Content Collections: `src/content/projects/*.md` с полями `title` (hy/ru/en), `category`, `district`, `year`, `area_m2`, `cover`, `gallery[]`, `featured: boolean`. На главной показывать `featured`.
- Изображения через `astro:assets` → AVIF/WebP, адаптивные размеры, lazy loading ниже первого экрана.
- Форма заявки — один серверный эндпоинт `POST /api/lead` (Astro hybrid/server output, адаптер Node).
- Деплой: Render (Web Service, Node) или Railway. Подготовить `render.yaml` или инструкцию для Railway.

## 5. Дизайн-система

### Цвета
```css
--graphite: #16161A;     /* тёмные секции, основной текст */
--graphite-2: #0F0F12;   /* подвал */
--stone: #F2EFEA;        /* основной светлый фон */
--stone-2: #E7E1D7;      /* альтернативная светлая секция */
--line: #CFC7BA;         /* тонкие разделители на светлом */
--muted: #55524C;        /* вторичный текст на светлом */
--muted-dark: #CFC9BE;   /* вторичный текст на тёмном */
--brass: #B8925A;        /* акцент: кнопки, метки на тёмном */
--brass-dark: #8A6636;   /* акцент на светлом фоне (контраст) */
```
Кнопки: фон `--brass`, текст `--graphite`, радиус 2px, высота ≥ 56px.

### Шрифты
- Заголовки (RU/EN): **Cormorant Garamond** 500/600.
- Основной текст (RU/EN): **Onest** 400/500.
- **ВАЖНО: оба шрифта не содержат армянских символов.** Для `/hy/` использовать **Noto Serif Armenian** (заголовки) и **Noto Sans Armenian** (текст). Переключать через `:lang(hy)`. Проверить, что армянский текст не падает в системный шрифт.
- Шрифты подключить локально (self-host), не с Google CDN.

### Характер
- Много воздуха: отступы секций 128px на десктопе, 72px на телефоне.
- Надзаголовки: 13px, uppercase, разрядка 4px, цвет акцента.
- Заголовки H1 ~104px / H2 ~56–64px на десктопе (clamp для адаптива).
- Тонкие линии 1px вместо карточек с тенями. Никаких теней, градиентов, скруглённых «пузырей».
- Лёгкие анимации появления при скролле (fade + сдвиг 16px), с учётом `prefers-reduced-motion`.

## 7. Форма заявки

- `POST /api/lead` → сообщение в Telegram через Bot API. Переменные окружения: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Токены только в env, никогда в коде и в репозитории.
- Валидация на сервере: имя 2–80 символов, телефон в формате армянского номера (+374…), тип объекта из списка.
- Антиспам: скрытое поле-ловушка (honeypot) + ограничение частоты по IP (например, 5 заявок в 10 минут).
- Ответ пользователю: понятное сообщение об успехе/ошибке на его языке, без перезагрузки страницы.
- Без чекбокса согласия форма не отправляется.
