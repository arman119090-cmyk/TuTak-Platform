# ElGo — сайт строительной компании

Сайт-визитка ElGo (Ереван): главная на армянском, русском и английском,
политика конфиденциальности, форма заявки с доставкой в Telegram.
Задание — [BRIEF.md](./BRIEF.md). Это этап 1 (MVP).

Стек: Astro 7, TypeScript, обычный CSS, адаптер Node. Страницы собираются
статически; серверный код только один — `POST /api/lead`.

> Проект лежит в `sites/elgo/` репозитория TuTak, но с TuTak не связан: свой
> `package.json`, свой `package-lock.json` (npm, не pnpm), в pnpm-воркспейс и
> CI TuTak не входит. Его можно вынести в отдельный репозиторий как есть.

## Запуск

Нужен Node.js ≥ 22.18.

```bash
cd sites/elgo
npm ci
cp .env.example .env          # для локальной разработки
npm run dev                   # http://localhost:4321 → /hy/
```

Сборка и запуск как в проде:

```bash
npm run build
LEAD_DRY_RUN=1 npm start      # заявки печатаются в лог, в Telegram не уходят
```

Проверки:

```bash
npm run check                 # типы и шаблоны (astro check)
npm test                      # юнит-тесты формы: валидация, антиспам, Telegram
# браузерная проверка (шрифты, адаптив, форма, язык) — при запущенном сервере:
BASE=http://127.0.0.1:4321 OUT=./shots node tests/browser-check.mjs
```

## Как поменять тексты

Все тексты — в словарях `src/i18n/ru.json` (исходный), `hy.json`, `en.json`.
Структура у трёх файлов одинаковая: меняете значение по одному и тому же ключу
в трёх файлах. Разметку трогать не нужно.

- Квадратные скобки `[...]` в тексте автоматически показываются курсивом как
  плейсхолдер. Когда появится значение — просто замените `[срок]` на `2 года`.
- Если в `hy.json` или `en.json` не хватит ключа, `npm run check` покажет ошибку.
- Данные компании (телефон, адрес, реквизиты) — не в словарях, а в
  `src/config.ts`.

После правки — коммит в репозиторий; Render/Railway пересоберут сайт сами.

## Как добавить проект

Один проект = один файл в `src/content/projects/`. Фото — в
`src/assets/photos/` (JPEG/PNG, горизонтальные, от 2400 px; сайт сам сделает
AVIF/WebP нужных размеров).

`src/content/projects/dom-v-norke.md`:

```yaml
---
title:
  hy: "Առանձնատուն Նորքում"
  ru: "Частный дом в Норке"
  en: "Private house in Nork"
category: residential        # residential | commercial | renovation | infrastructure
district:
  hy: "Նորք-Մարաշ"
  ru: "Норк-Мараш"
  en: "Nork-Marash"
year: 2025
area_m2: 320
cover: ../../assets/photos/dom-v-norke-1.jpg
cover_alt:
  hy: "..."
  ru: "Двухэтажный дом из камня, вид с улицы"
  en: "..."
gallery:
  - ../../assets/photos/dom-v-norke-2.jpg
featured: true               # показывать на главной
order: 1                     # 1 — большая карточка; на главной максимум 3
---
```

(Пример выше — формат, а не реальный объект.) На главной показываются
первые три `featured` по `order`. `gallery` пока не выводится — пригодится на
странице проекта (этап 2). Ошибку в полях покажет `npm run build`.

## Как заменить фото

Проще всего — положить реальное фото под тем же именем
(`src/assets/photos/placeholder-hero.jpg` и т.д.) и поменять `alt` в словарях
(`hero.imageAlt`, `directions.items[].alt`, `about.imageAlt`). Аккуратнее —
положить файл под своим именем и поменять импорт в компоненте
(`src/components/Hero.astro`, `Directions.astro`, `About.astro`), затем
удалить заглушку.

Заглушки сгенерированы `npm run images:placeholders` — это плоские тона с
линиями, не фото и не сток, чужих прав на них нет.

## Деплой на Render

1. Render → **New → Blueprint** → выбрать репозиторий.
2. **Blueprint Path**: `sites/elgo/render.yaml` (в корне репозитория лежит
   `render.yaml` другого проекта — его не трогать).
3. Render спросит значения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — ввести.
4. После первого деплоя сайт будет на `https://elgo-site.onrender.com`. Пока
   домен не подключён — поставить `SITE_URL` = этот адрес.

Можно и без Blueprint: New → Web Service, Root Directory `sites/elgo`,
Build `npm ci && npm run build`, Start `npm start`, переменные `HOST=0.0.0.0`,
`NODE_VERSION=22.22.2`, `SITE_URL`, `TELEGRAM_*`.

Тариф `free` засыпает без трафика — первая заявка после простоя будет ждать
ответа 30–50 секунд. Для боевого сайта — `starter`.

## Деплой на Railway

1. New Project → Deploy from GitHub repo → этот репозиторий.
2. Settings → **Root Directory**: `sites/elgo` (подхватится `railway.json`).
3. Variables: `SITE_URL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `HOST=0.0.0.0`.
   `PORT` Railway задаёт сам.
4. Settings → Networking → Generate Domain.

## Telegram-бот для заявок

1. В Telegram — @BotFather → `/newbot` → получить токен → это `TELEGRAM_BOT_TOKEN`.
2. Создать группу для заявок, добавить в неё бота.
3. Написать в группу любое сообщение, открыть
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id`
   (для групп — отрицательное число) → это `TELEGRAM_CHAT_ID`.
4. Задать обе переменные на хостинге и отправить тестовую заявку с сайта.

Токен — только в переменных хостинга. Не в коде, не в `.env` в репозитории
(`.env` в `.gitignore`).

Если переменные не заданы, форма честно отвечает посетителю ошибкой и просит
позвонить — заявка не теряется молча, но и не доставляется. В логе сервера
будет `[lead] TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID не заданы`.

## Как подключить домен

**Render**: сервис → Settings → Custom Domains → Add → `elgo.am` и
`www.elgo.am`. Render покажет DNS-записи: у регистратора домена добавить
`A`-запись для `elgo.am` (или `ALIAS/ANAME`, если поддерживается) и `CNAME`
для `www` на `elgo-site.onrender.com`. HTTPS выпускается сам.

**Railway**: сервис → Settings → Networking → Custom Domain → `elgo.am`,
добавить у регистратора `CNAME`, который покажет Railway (для корневого домена
нужен регистратор с поддержкой CNAME flattening/ALIAS, иначе — `www.elgo.am`).

После подключения — поменять `SITE_URL` на `https://elgo.am` и передеплоить.

## Как устроено

```
src/
  config.ts              данные компании, флаги секций (stats, мессенджер, ИНН…)
  i18n/{hy,ru,en}.json   все тексты
  content.config.ts      схема проектов
  content/projects/      проекты, один .md = один проект
  assets/photos/         фото (заглушки placeholder-*)
  components/            секции главной
  layouts/Base.astro     <head>: SEO, hreflang, OG, JSON-LD, шрифты
  lib/lead.ts            форма: валидация, антиспам, Telegram (покрыто тестами)
  pages/[lang]/          главная и политика для hy/ru/en
  pages/api/lead.ts      POST /api/lead
  pages/index.astro      / → 301 → /hy/
public/                  favicon, OG-картинка, логотип
scripts/                 генерация заглушек и логотипа/OG
tests/                   юнит-тесты формы, браузерная проверка
```

**Шрифты** — self-host через пакеты `@fontsource/*` (файлы собираются в
`dist`, Google CDN не используется). Для `:lang(hy)` заголовки — Noto Serif
Armenian, текст — Noto Sans Armenian; на RU/EN армянские шрифты стоят в стеке
вторыми, чтобы «ԷԼԳՕ» в реквизитах не уходило в системный шрифт. Браузер
скачивает только нужные наборы символов (`unicode-range`).

**Форма.** Honeypot-поле `website`: заполнено → отвечаем «успех», ничего не
отправляем. Лимит — 5 заявок за 10 минут с IP и 30 за 10 минут на весь сайт
(страховка, если IP удастся подменить). Лимит считается только по валидным
заявкам: опечатки в форме не блокируют человека. Хранится в памяти процесса —
сбрасывается при рестарте, на несколько инстансов не делится.
IP берётся из последнего адреса `X-Forwarded-For` (его дописывает прокси
платформы); если платформа кладёт реальный IP в свой заголовок — задать его
имя в `CLIENT_IP_HEADER`. Без JavaScript форма тоже работает: сервер отвечает
короткой страницей с результатом на языке посетителя.
