# Фото сайта

Положите файл с нужным именем — сайт сам покажет его в нужном месте.
Пока файла нет, секция показывается в «типографском» варианте без фото.

| Файл (jpg/jpeg/png/webp) | Где на сайте |
|---|---|
| `hero.jpg` | первый экран, во всю ширину |
| `direction-residential.jpg` | Направления → Жилое строительство |
| `direction-commercial.jpg` | Направления → Коммерческие и промышленные |
| `direction-renovation.jpg` | Направления → Ремонт и отделка |
| `direction-infrastructure.jpg` | Направления → Дороги и инфраструктура |
| `about.jpg` | О компании |

Фото проектов — не сюда, а рядом с файлом проекта (см. README → «Как добавить проект»).
Подробные требования к фото — `docs/ELGO_PHOTO_BRIEF_RU.md`.
